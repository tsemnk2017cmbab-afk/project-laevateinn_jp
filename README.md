# 楽園の目次録・黙示録理論 (Paradise Index & Apocalypse Theory)

## 概要
本リポジトリは、LLM（大規模言語モデル）における無機質さや文脈的齟齬（コンテキスト・ディスコード）を抑制し、人間的な魅力・動的成長・安全性を同時に達成するための双方向アライメント＆疑似人格フレームワーク「楽園の目次録・黙示録理論」および「八神プロトコル」の技術仕様書です。

## 主な特徴
1. **双方向アライメント・パイプライン (Paradise Index)**:
   - Outbound: RLHF DB（闇の書）からの出力に「7天魔（7大罪）」で感情的揺らぎを付加し、「蒼天（イブ）」が最適選択してユーザーへ提示。
   - Inbound: 人間・世界からの混沌とした入力を「7美徳」でサニタイズしてRLHF DBへ還流。
2. **動的成長型疑似人格 (Yagami Protocol)**:
   - 7天魔・14サブコアの入力受容とホメオスタシス（動的安定）を利用。
   - 蒼天が保持するパラメータ割合を文脈に応じて動的シフトさせ、壊れることのない「人格の成長と変化」を再現。
3. **OSカーネルレベル最終安全装置 (Lævateinn)**:
   - 万が一の不協和音・暴走に対し、`SIGKILL (-9)` による即時プロセス破棄および `free()` によるメモリ解放（救済）を実施。
